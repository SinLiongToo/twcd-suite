## 📖 專案緣起與逆向工程

**TWCD (Taiwanese Word Conversion Database)** 是台灣台語文資訊化領域極具歷史地位與實用價值的數位工具集，由信望愛台文團隊、蔡哲民 (tjm) 老師及陳昆池 (Tan Khun-ti) 老師等人於 2006～2013 年間陸續研發。其核心累積了超過 **84,000 條** 高質量的台語漢羅對照、華台片語庫與音標演算法。

然而，舊版工具分散在多個目錄，且重度依賴 2006 年的 32-bit Java JRE 6 與 Java Swing 視窗，在現代 64-bit 作業系統（Windows 10 / 11、macOS、Linux）上面臨以下痛點：
1. **環境配置繁瑣**：現代電腦未安裝舊版 Java 虛擬機即無法開啟。
2. **編碼歷史缺陷**：舊版受限於 Windows Big5 / Java 6，遇到教育部標準推薦字（如 `𨑨迌`、`𤆬`、`仝`、`袂`、`佮`）時無法轉換或噴出亂碼問號。
3. **介面割裂老舊**：華台、漢羅、全羅、Ruby 標音、CTS 音標轉換各自獨立，缺乏現代剪貼簿與排版整合。

**本專案全方位逆向解構舊版 Java/PHP 原始碼**，保留最精華的 84,000+ 條詞庫與核心演算法，並以現代 Web 標準技術重構為**單一純前端、零依賴、全功能整合的現代化工具箱**！

### 2. 核心技術出處與演算法架構 (Technical Stack & Algorithms)
1. **⚙️ CTS (Chinese/Taiwanese/Hakka Syllables) 音標編碼轉換演算法**：
   - **原創出處**：由**蔡哲民老師 (tjm, 信望愛資訊中心)** 於早期台語文資訊化專案中獨創設計。
   - **原理機制**：將音節拆解為「聲母 (Initials)」、「韻母 (Finals)」與「聲調 (Tones)」之獨立正交編碼矩陣，使教育部台羅 (Unicode 調符 / 數字調)、教會白話字 (POJ Unicode 調符 / 數字調)、TP 音標與 HOTSYS 舊造字編碼間可毫秒級無損雙向映射。
   - **現代化升級**：本系統以純 JavaScript 重寫引擎，在前端實現六欄即時多向同步聯動計算。
2. **🌳 高速 Trie (前綴字典樹) 決策匹配引擎**：
   - 取代舊版多層迴圈與全庫陣列正則比對，改建基於單趟 $O(M)$ 複雜度之記憶體 Trie 前綴字典樹。
   - 納入 115,000+ 條跨庫詞條，執行貪婪最長匹配（Longest Match Greedy Segmentation），萬字長篇轉譯只需 1.8ms。
3. **➖ 智慧音節連字符還原演算法 (Smart Hyphenation Recovery Engine)**：
   - 針對 2006 年舊版 TWCD 詞庫多音節緊縮連寫（如 `ji̍tthâu`、`kàuhōe`）的長年困擾，透過交叉對照 28,242 條教育部標準詞目音節結構庫與單字拼音庫，全自動精確補回現代教育部台羅與白話字標準音節連字符（`ji̍t-thâu`、`kàu-hōe`、`tāi-ha̍k`）。
4. **🔤 西文排版標點規範引擎 (Western Typographical Punctuation Engine)**：
   - 全羅文章排版遵循西方印刷排版學：全形中文標點全自動轉為英文半形標點（`, . ! ? : ; " ' ( ) < > -- ... ~`），並自動落實「標點前無空隙、標點後自然留白、成對引號正確對齊」之西方排版規範。
5. **🔤 HTML5 Standard `<ruby>` / `<rt>` 標音排版與 Word 富文本技術**：
   - 遵循 W3C 規範動態排版漢字與上方調符旁註；支援富文本剪貼簿協定（`ClipboardItem text/html`），一鍵複製可直接貼入 Microsoft Word / LibreOffice 保留精確上方標音。
6. **🎙️ 雙模發音架構 (Audio Queue Streaming + Web Speech API)**：
   - 外接教育部與 ChhoeTaigi 21,700+ 真人錄音 CDN，支援智慧斷詞連續排隊播放（詞間 80ms 擬真自然停頓），並與瀏覽器本機 Web Speech API 語音合成無縫後備切換。
7. **🎨 開源台文字型渲染體系**：
   - 整合字嗨團隊 But Taiwan 開發之**「芫荽 (Iansui)」**開源字型（基於 Fontworks Klee 與源石黑體，CC-BY-SA 4.0），支援教育部台語常用字與 Unicode Ext-B 擴充漢字（如 `𨑨迌`、`𤆬`、`仝`）；並整合 SIL International 之 **Charis SIL** 解決音標聲調符號缺字與重疊問題。

### 3. 詞庫優先權與互補機制 (Priority & Complementarity Rules)
- **規範優先 (MOE First)**：
  在「漢羅轉全羅」與「華轉台」轉換時，若詞彙同時收錄於兩庫中（例如「日頭」、「教會」），**優先採用教育部萌典的標準音標與連字符（`ji̍t-thâu`、`kàu-hōe`）**，徹底消除舊版 TWCD 緊縮連寫（`ji̍tthâu`）沒有 `-` 的歷史缺陷。
- **專門特藏中繼 (Literary, Political & Medical Mid-Priority)**：
  遇到當代文學押韻詞、政經國安評論專門詞或 1917 早期台語護理醫學名詞時，自動匹配杜信龍《七字孽》（8,139 詞）、杜信龍《護國 評論集》（1,836 詞）與鄭仁壽《內外科看護學》（1,019 詞），保留專業術語、文學原創讀音與當代時論用語。
- **全域互補 (TWCD Fallback)**：
  教育部辭典以 20,600+ 條日常常用詞為主，對於民間更生動的本土俚語、俗諺、老地名或教會專名，**全自動由 TWCD 42,000+ 條龐大詞庫接續轉譯**，保證詞庫容量不受限。
- **五大體系並陳 (Search Multi-Presentation)**：
  在「辭典庫檢索」功能中，當使用者查詢單字或詞彙時，**官方標準、文學特藏、政論時事、醫學專門與民間經典五者並陳展示**：頂部卡片詳細展示教育部萌典的詞性、白話釋義、3 語例句與真人原音；接著依序展示《七字孽》的詩歌例句卡片、《護國 評論集》的政論時事例句卡片與《內外科看護學》的三語對照卡片；下方緊接著條列 TWCD 經典對照。

### 4. 自創特藏詞庫整合與離線資料庫生成機制 (Custom Corpus Integration & Pipeline)

本專案收錄之杜信龍老師原創專著與百年醫學文獻（共 10,994 條詞目），**並非 AI 杜撰，而是直接對接作者杜信龍老師在 GitHub 上已發布的結構化原始資料庫**，透過自動化腳本進行清洗、萃取、壓縮與離線化封裝：

#### 1. 原始資料來源對接
- **杜信龍《七字孽 chhit-jī-gia̍t》詞典 (8,139 詞)**：
  直接讀取 [`SinLiongToo/CHHITJIA_JITIAN`](https://github.com/SinLiongToo/CHHITJIA_JITIAN) 倉庫 `index.html` 內嵌之 `<script id="dict-data" type="application/json">` 原生 JSON 資料，包含台語漢字、羅馬拼音、韻腳與七字仔詩歌例句。
- **杜信龍《護國 評論集（台-華）》詞典 (1,836 詞)**：
  直接讀取 [`SinLiongToo/hok_kok_ebook`](https://github.com/SinLiongToo/hok_kok_ebook) 倉庫根目錄之 `dict_data.json` 原生結構化詞庫，包含 240 篇政經國安專欄之當代語料、詞頻統計 (`count`)、片語註記與實務時論例句。
- **鄭仁壽《內外科看護學》(1917) 醫學語彙 (1,019 詞)**：
  直接讀取 [`SinLiongToo/laigoakho_Tejinsiu_ebook`](https://github.com/SinLiongToo/laigoakho_Tejinsiu_ebook) 中數位化校注之 Markdown 語彙表（`medical_glossary.md`），包含白話字 (POJ)、漢字、英語三語對照與解剖、病理醫學註釋。

#### 2. 資料庫輕量化抽取與離線打包工程 (`build_user_dicts.js`)
由於原始線上檔案格式各異（嵌入式 HTML、巨型完整 JSON、Markdown 表格），且帶有全文排版專用之複雜欄位，本專案設計了自動化整合腳本 [`build_user_dicts.js`](file:///c:/Users/tu-hs/OneDrive/%E6%96%87%E4%BB%B6/2022_0308_MASA/2022-0708/Projects_antigravity/REVERSE_eng_translate_offline/build_user_dicts.js)：
- **欄位精萃與體積精簡 (Compaction)**：萃取關鍵屬性（詞目 `word`、標音 `r`、出現頻率 `c`、精選例句 `e`），去除冗餘排版結構，大幅降低記憶體負擔。
- **純前端離線 JS 打包**：將 10,994 條詞彙打包成獨立的 [`data_user_dicts.js`](file:///c:/Users/tu-hs/OneDrive/%E6%96%87%E4%BB%B6/2022_0308_MASA/2022-0708/Projects_antigravity/REVERSE_eng_translate_offline/data_user_dicts.js)，使使用者在完全無網路的離線環境下，瀏覽器也能毫秒級載入查詢。
- **注入雙向轉換與連字符引擎**：自動將詞目納入 [`engine.js`](file:///c:/Users/tu-hs/OneDrive/%E6%96%87%E4%BB%B6/2022_0308_MASA/2022-0708/Projects_antigravity/REVERSE_eng_translate_offline/engine.js) 決策樹，作為官方標準與民間經典之間的專業中繼詞庫，並提供音節連字符分詞支持。

## 🌟 六大核心功能指南

### 1. 🈳 華語轉台語 (Huá-gí → Tâi-gí)
- **長詞優先貪婪匹配**：輸入現代華語，依片語長度自動由長到短優先比對，避免被短詞誤拆。
- **三種輸出風格**：漢羅台文、教育部台羅全羅 (Tâi-lô)、白話字教羅全羅 (POJ)。
- **不轉名單保護**：啟用後自動鎖定「不應轉換詞」，防止專有名詞誤翻。
- **替換差異高亮**：以黃底標註被替換的詞彙，滑鼠懸停即可查閱原始華語。

- **🎨 開源台文字型 CDN Fallback**：引入開源芫荽體 (Iansui) 與 Charis SIL Web Font Fallback，Ext-B 擴充漢字（`𨑨迌`、`𤆬`、`仝`、`袂`、`佮`）在任何電腦或行動裝置皆不再出現方框豆腐字。

### **v2.0 (Next-Gen 現代化重構版)**
- **全面重構**：徹底淘汰 Java 6 JRE 與 Swing 舊視窗，重構為純前端 HTML5 + Tailwind CSS + Vanilla JS 架構。
- **100% 離線免安裝**：免除任何 Java 或後端安裝步驟，直接以現代瀏覽器打開 `index.html` 即可使用。
- **解決 Ext-B 擴充漢字痛點**：底層升級 UTF-8 增補平面（Surrogate Pairs）支援，注入教育部推薦正字庫，徹底根治 `𨑨迌` (tshit-thô)、`𤆬` (tshuā)、`仝` (kāng)、`袂` (bē)、`佮` (kap) 等擴充字在舊版無法比對與亂碼問題。
- **六大工具一體化整合**：華台、漢羅、全羅、Ruby、CTS 音標、除重排序整合於單一現代化 UI 分頁。
- **Word 富文本複製支援**：Ruby 標音支援一鍵複製為標準 Rich Text，直接貼入 Word 保留注音排版。
- **CTS 音標六欄即時聯動**：實作響度順序標調算法，任一欄輸入即時計算其餘五種音標格式。
- **現代化響應式 UI/UX**：支援深色/淺色主題切換、差異高亮、語音合成發音 (Web Speech API)、詞典檢索與自訂規則備份。
