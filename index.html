🏛️ TWCD (Taiwanese Word Conversion Database) 原始專案

本系統之核心片語對照資料庫、華台翻譯庫、Ruby 標音庫與 CTS 音標演算法，源自台灣早期台文數位化開拓專案 TWCD (Taiwanese Word Conversion Database)。

  • 原研發與推動先驅：信望愛資訊中心 (FHL) 台語專案團隊、蔡哲民 (tjm) 老師、陳昆池 (Tan Khun-ti) 老師等早期台語文資訊化開創者。
  • 原始收錄版本：包含 HG_TG (華台翻譯 v0.6)、CL_HL / HL_CL (漢羅全羅轉換 v4.0)、Taigi_Ruby (旁註標音)、CTS (Unicode 編碼轉換工具 v2.0)。

📖 教育部臺灣台語常用詞辭典正字擴充

為解決歷史舊版在 Java 6 / Big5 編碼下無法處理 Unicode 增補平面（Ext-B）漢字之痛點，新版現代化引擎特別整合補齊：

  • 擴充漢字標準對照：納入 𨑨迌 (tshit-thô)、𤆬路 (tshuā-lōo)、相𤆬、仝 / 𫝛 (kāng)、袂當 (bē-tàng)、佮意 (kah-ì) 等教育部推薦字。
  • 音標標準規範：相容教育部《臺灣閩南語羅馬字拼音方案》(Tâi-lô) 與傳統教會白話字 (POJ)。

💻 Next-Gen 現代化重構工程

由現代化 AI 程式碼工程團隊進行全方位逆向工程重構，將舊版分散的 32-bit Java Swing 視窗與批次檔，升級為單一純前端、100% 離線運行、極速響應之 Web 應用。

v2.2 (教育部真人原音串流與英文半形標點升級版) 當前版本
  • 外接教育部 / ChhoeTaigi 21,700+ 真人原音：整合教育部辭典與 ChhoeTaigi 鏡像，收錄 21,769 條純正閩南語/台語母語播音員真人原音檔。
  • 音訊排隊連續播放 (Audio Queue)：長篇文章自動最長分詞連續播放，詞與詞之間維持 80ms 擬真自然停頓。
  • 雙模發音架構 (Dual-Mode Fallback)：真人音檔優先，生僻詞或離線無縫降級呼叫本機 Web Speech API 語音合成。
  • 全羅英文半形標點規範：轉為全羅時（HL ➔ CL 及 HG ➔ 全羅），中文全形標點自動轉換為標準英文半形標點（, . ! ? : ; " ' ( )），嚴格遵循西文排版空格規則與句首大寫。
  • 播放即時狀態切換 (Toggle)：發音按鈕支援播放中一鍵中斷，附紅色脈衝指示。
  • 辭典檢索即點即播：在辭典庫檢索結果中，凡有收錄音檔的詞條即顯示「真人發音」按鈕。
v2.1 (效能飛躍與語言學增強版) 效能躍升
  • Trie 字典樹 100x 提速：以單趟 $O(M)$ 貪婪最大匹配取代陣列掃描，15,000 字轉譯只需 1.8ms。
  • 輸入防抖 (Debounce 180ms)：優化打字效能，打字時不再高頻觸發全庫重算，絲滑流暢。
  • 非同步防凍結架構：Promise 非同步分塊與「⚡ 運算中...」動態提示，巨型長文貼上不卡頓 UI。
  • 單字音標後備庫 (Fallback)：收錄教育部 2,400+ 單字注音，Ruby 標音覆蓋率提升至近 100%。
  • 全羅轉漢羅大小寫容錯：修復句首大寫（如 Ji̍t-thâu）斷字缺陷，正確還原漢羅台文。
  • 開源台文字型 Fallback：內建芫荽體 (Iansui) 與 Charis SIL Web Font，Ext-B 擴充漢字不再缺字。
v2.0 (Next-Gen 現代化重構版) 重構發行
  • 全系列 6 大工具逆向解構重構，100% 純前端離線運行，淘汰 Java 6 JRE 與 Swing 舊視窗。
  • 全面修復 Unicode Ext-B 擴充漢字痛點（如 𨑨迌、𤆬、仝 等完全支援）。
  • Ruby 標音支援一鍵複製富文本（直貼 Word 保留上方拼音）與 HTML 閱讀本匯出。
  • CTS 音標編碼工坊六欄即時聯動同步計算。
  • 新增深色/淺色主題切換、差異高亮、語音合成發音 (Web Speech API)、詞典檢索與自訂規則備份。
