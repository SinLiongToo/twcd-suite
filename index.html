🏛️ 教育部《臺灣台語常用詞辭典》 / g0v 零時政府「萌典」 官方權威標準

收錄 20,604 條精選台語詞目與 21,700+ 條母語播音員真人發音原音檔。每條詞目均具備教育部推薦漢字、現代標準音節連字符（`-`）、台羅/白話字音標、詞性分類、華語白話釋義與生活對話三對照例句（台語漢字、台羅拼音、華語翻譯）。

  • 原始著作權：中華民國教育部《臺灣閩南語常用詞辭典》（依「政府資料開放授權條款」及 CC BY-ND 3.0 臺灣版釋出）。
  • g0v 萌典專案：由唐鳳 (Audrey Tang) 與開源社群清洗編排為標準 UTF-8 JSON，衍生編輯著作權依 CC0 1.0 (公眾領域貢獻宣告) 開放。
  • 語音鏡像：由 ChhoeTaigi (找台語) 開源團隊維護高可用 CDN 音檔服務。

  • 原研發先驅：信望愛資訊中心 (FHL) 台語文專案團隊、蔡哲民 (tjm) 老師、陳昆池 (Tan Khun-ti) 老師、鄭良偉教授等早期台語文資訊化開創者。

⚖️ 詞庫階層決策與雙庫互補架構 (Priority & Complementarity)

  • 教育部萌典為先 (MOE First)：兩庫皆收錄之詞目優先採用教育部推薦漢字與標準連字符（`-`），消弭歷史緊縮連寫缺陷。
  • 當代文學/時論/醫學特藏中繼 (Specialized Dictionaries Mid)：精準命中詩詞押韻音、時事評論新詞與百年護理專有名詞。
  • TWCD 補其不足 (TWCD Fallback)：未收錄於規範庫之生動民間俚語、俗諺老詞，全自動由 TWCD 42,000+ 龐大片語庫接續轉譯。
  • 辭典檢索五體並陳：查詢單字詞時同時並列五大系統釋義、例句與原音，方便學術比較。

⚙️ CTS (Chinese/Taiwanese/Hakka Syllables) 音標編碼轉換演算法 核心演算法

由蔡哲民老師 (tjm) 於信望愛資訊中心專案中原創研發。演算法透過將台語與客語音節之「聲母 (Initials)」、「韻母 (Finals)」與「聲調 (Tones)」拆解為獨立維度矩陣，實現不同標音規範間的無失真雙向正交轉換。

  • 完整支援體系：教育部台羅 (Unicode/數字調)、教會白話字 POJ (Unicode/數字調)、台灣語言音標方案 (TP)、HOTSYS 造字相容編碼。
  • Next-Gen 升級：純 JavaScript 逆向重製，實現六欄即時多向同步聯動計算。

🌳 高效 Trie (前綴字典樹) 決策匹配引擎 100x 效能躍升

徹底替換舊版多輪正規表達式與全陣列掃描，改以現代記憶體前綴字典樹 (Trie) 進行單趟 $O(M)$ 貪婪最長匹配 (Longest Match Greedy Segmentation)。

  • 瞬時轉譯：處理 15,000 字以上長篇漢羅或全羅文章僅需 1.8 毫秒。
  • 防凍結非同步調度：搭配 180ms 輸入防抖 (Debounce) 與 Web Worker/Promise 分塊架構，長文轉譯打字絲滑不卡頓。

➖ 智慧音節連字符還原演算法 (Smart Hyphenation Recovery Engine) 語音結構重構

突破舊版 TWCD (2006) 42,000+ 條詞庫將多音節緊縮連寫（如 ji̍tthâu、kàuhōe）的歷史局限。全新研製音節分析還原演算法，交叉比對 28,242 條教育部標準詞目音節庫與單字注音庫，全自動將緊縮拼音精準還原為現代標準音節連字符（Ji̍t-thâu、Kàu-hōe、tāi-ha̍k、tông-kám）。

🔤 西文排版標點規範引擎與 HTML5 Ruby 富文本技術

  • 西文標點排版規範：轉為全羅時全自動將中文全形標點轉換為標準英文半形標點（, . ! ? : ; " ' ( ) < > -- ... ~），遵循西文印刷規範（標點前無空隙、標點後自然留白、成對引號正確規整）。
  • HTML5 Standard <ruby> 排版：依 W3C 規範動態渲染漢字與上方調符旁註；支援富文本剪貼簿協定（ClipboardItem text/html），一鍵複製可直接貼入 Microsoft Word / LibreOffice 保留精確上方標音。
  • 雙模發音架構 (Audio Queue Streaming)：外接教育部與 ChhoeTaigi 21,700+ 真人錄音 CDN，支援智慧斷詞連續排隊播放（詞間 80ms 擬真自然停頓），並與瀏覽器本機 Web Speech API 語音合成無縫後備切換。
